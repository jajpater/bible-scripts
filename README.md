# Shortcut scripts for diatheke

Start de interactieve manager vanuit deze repository met `./bible-symlinks`.
Kies optie 3 om bijvoorbeeld een `typ`-variant aan `svv` toe te voegen.

Met `./svvtyp "Joh 3:16"` gebruik je de lokale snelkoppeling. Wijzigingen aan
de repository worden na een Nix-rebuild ook beschikbaar in je installatie.

Zie [de Nederlandse handleiding](README-bible-nl.md) of
[the English manual](README-bible-en.md) voor alle mogelijkheden.
